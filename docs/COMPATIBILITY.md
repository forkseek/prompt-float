# Windows 兼容性检查

## 已自动检测

设置中的“高级设置与费用保护 → 诊断与兼容性”会显示并可导出：

- 应用、Electron 和 Node 版本；
- 在线状态及当前路由的 Chromium 代理解析结果；
- 主窗口位置、尺寸、最小化/最大化和置顶状态；
- 所有显示器的边界与 DPI 缩放倍数；
- 最近 200 条脱敏生命周期、路由测试和优化事件。

日志保存在 Electron 的系统日志目录，单文件达到 1 MB 后轮换一次。报告和日志不包含 API Key、MCP Token、提示词正文或模型输出正文。

## 发布前人工矩阵

| 场景 | 验证内容 | 合格标准 |
| --- | --- | --- |
| Windows 11，100%/150%/200% DPI | 首次弹窗、设置、主界面 | 无裁切；底部操作可达 |
| 双显示器，不同 DPI | 拖动、最小化、恢复、重开 | 窗口可移动且不强制置顶 |
| 系统代理：直连/PAC/HTTP 代理 | 诊断代理、模型连接 | 代理结果可见；失败信息可定位 |
| 离线、DNS 失败、TLS 失败、超时 | 路由测试和优化 | 原状态保留；显示可执行错误提示 |
| 企业自定义 CA | HTTPS 路由 | 仅在系统证书链信任时成功；应用不绕过证书校验 |
| 安装版升级 | 设置和凭据 | 版本升级后设置仍可读取 |
| 便携版 | 启动与退出 | 可运行；自动更新明确停用 |

自定义 CA、代理和多显示器需要目标组织环境，仓库中的诊断能力不能替代真实环境验收。每次发布应保存一份不含敏感数据的人工测试记录。
